販売管理 eSales ／ FileMaker「eSales2」移行 ／ 2026-11-14 第1案

eSales 画面イメージ案と機能構成

新しい販売管理アプリの見た目と流れを、決定前のたたき台として示します。画面内の会社名・金額はすべて架空のサンプルです。

1

システムの特徴

入口

販売管理だけの独立したアプリ

専用のURL・アイコン・ホーム画面を持ち、Dock やホーム画面に「eSales」として追加できます。ログインIDとパスワードはタスク管理と共通です。

流れ

見積から入金までが1本の線で見える

伝票を開くと、見積・受注・売上・請求・入金のどこまで進んだかが上部に並びます。押すとその伝票へ移ります。

操作

1つの画面で完結、キーボードで速い

伝票ごとに別ウインドウを開きません。一覧の横に詳細が開き、明細は Enter と Tab で打ち進められます。

端末

Mac・Windows・iPad・iPhone で同じ機能

iPhone 専用の画面を作り分けず、同じ画面が幅に合わせて並び替わります。現場での写真つき作業報告もそのまま使えます。

正確さ

金額は現行と1円単位で突き合わせ

消費税と請求金額の計算を1か所にまとめ、過去の締め月を締め直して FileMaker の結果と一致するかを自動で確かめます。

費用

無料枠で運用

既存の Cloudflare と Supabase の無料枠に収めます。写真と帳票は Cloudflare R2（10GBまで無料）に置き、使用量を管理画面に表示します。

5

デザインテーマ候補

3案とも、状態を表す色（済＝緑、注意＝黄、要対応＝赤）と、売上系＝青・仕入系＝茶の区別は共通です。違いは基調色、角の丸み、余白、ナビの濃さです。

案色印象向いている使い方気をつける点
A 藍
推奨
白地に藍。帳簿のように落ち着いた、標準的な業務画面PC で一覧と明細を長時間見る使い方。1画面に多くの行を出せる現行の青と近く、変わった実感は控えめ
B 若竹
淡い緑と大きめの角丸。やわらかく明るいiPad・iPhone での指操作。余白が広く押しやすい1画面の行数が約1〜2割減る。「済」の緑と基調色が近いので、状態は必ず文字でも示す
C 墨と朱
墨色のナビに朱の差し色。印影を思わせる引き締まった画面ナビと作業領域がはっきり分かれ、大きな画面で映える朱が「要対応」の赤と近い。警告は赤の塗りではなく、記号と文字で区別する必要がある
共通の選択肢 1

表示密度

「標準」と「コンパクト」を利用者ごとに切り替えられるようにします。PC では コンパクト、タブレットでは標準が既定です。

共通の選択肢 2

ダークモード

端末の設定に合わせて自動で切り替える案と、明るい画面に固定する案があります。帳票の見え方は変わりません。

共通の選択肢 3

タスク管理との関係

別アプリとして見分けやすくするため、基調色はタスク管理と変えることを勧めます。部品の形と操作は揃えます。
