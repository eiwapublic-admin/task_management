# eSales2（FileMaker）現行システム参照資料

- 作成日: 2026-11-14。FileMaker データベースデザインレポート（DDR）から機械抽出したもの
- 用途: 開発計画 [`esales-plan.md`](./esales-plan.md) の詳細設計・データ移行で、現行の項目名と機能名を引くための索引
- **元の DDR・画面ショット・帳票 PDF はリポジトリに入れていない**（得意先名・金額を含むため）。計算式やスクリプトの中身が必要なときは、依頼元に zip を再アップロードしてもらう（引き継ぎ書 [`esales-handoff.md`](./esales-handoff.md) 4章）

## 凡例

- 型の表記: 無印＝テキスト／`N` 数字／`D` 日付／`TS` タイムスタンプ／`時刻`／`バイナリ` オブジェクト／`S, N` 集計
- 型の前に `:T` `:N` などが付き「計算」由来のものも含む（DDR 上は「計算結果」）。**新 DB では計算・集計・`g_`（グローバル）・`c_`・`flg_`・`gc_` で始まる項目は列として持たない**（計画書 6-1）
- 各テーブル末尾の共通項目（選択／作成・修正タイムスタンプ／作成・修正アカウント／作成・修正ユーザ名／主キー／最終変更フィールド／修正時システム環境／レコードタイトル）は省略
- 件数は計画書 3-2 を参照
