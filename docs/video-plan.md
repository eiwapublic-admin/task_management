# 解説動画 制作方針

最終更新: 2026-07-06
対象システム: タスク管理システム（Cloudflare 版）。設計は [`task-management-spec-cloudflare.md`](./task-management-spec-cloudflare.md)、運用は [`HANDOFF.md`](./HANDOFF.md) を参照。

---

## 1. 目的・要件

- **目的**: 担当者にシステムを使ってもらうための導入資料。短時間で「有意義・便利・簡単」が伝わること
- **視聴環境**: PC
- **長さ**: 約2分（ショート動画のようなテンポ重視。説得力のためなら多少の超過は可）
- **ナレーション**: あり
- **編集の余地**: 最終仕上げ・微調整を発注側で行えること。Canva 連携済みのため Canva 上での調整も可

### 動画で伝えること（発注側指定の要件）

- **利用の目的（便利・有意義）**: 雑多なメールの中から担当とタスクをわかりやすく整理し、取りこぼし・対応忘れを防ぐ。他の担当者の状況も見える
- **利用の手順（簡単操作）**: 未処理タスクで内容確認 → 必要に応じてメール確認・返信 → 処理したらステータスを進行 → 完了まで取りこぼしなく見届ける
- **自動化されている点（賢さ）**: メールの抽出と仕分け／カレンダーイベントの当日分取得／返信を AI が検知して未処理→返信済みへ自動移動／返信先アドレスを判断して返信メールを自動構築
- **設定画面の紹介**: 自動取得のタイミング指定、振り分けルールの指定、Anthropic API クレジットの状況確認と課金（消費速度の見込み）
- **情報源の流れ**: `if@eiwa-up.jp` 宛メール → `eiwa.public@gmail.com` に転送 → AI が抽出してタスク化。同アカウントのカレンダーイベントも当日分をタスク化。**各担当者はメールの CC に `if@eiwa-up.jp` を入れる必要がある**ことを理解してもらう

## 2. 構成案（約2分半）

| # | パート | 目安 | 内容 |
|---|---|---|---|
| 1 | 導入 | 15秒 | 「メールを読んで振り分ける作業が自動になりました」— 課題と結論を先に |
| 2 | 仕組み | 20秒 | Gmail・カレンダー → AI が自動分類 → カンバンに登録、を図解1枚で |
| 3 | 日常の使い方 | 90秒 | ログイン → カンバン → タスク詳細（AI判定の理由・メール参照・返信）→ ステータス移動 → 返信の自動検知、の実操作 |
| 4 | 締め | 15秒 | 「基本は放置でOK。見るのはカンバンだけ」＋困ったときはログ画面 |

演出: 1カット3〜6秒、テロップ併用でキビキビ進行。

## 3. 制作フローと分担

1. **台本・絵コンテ**（Claude）— ナレーション原稿＋カット割り＋テロップ文言を1ドキュメントに。最初のレビュー対象
2. **画面素材**（Claude）— ローカルでアプリを起動しデモ用データを投入、Playwright で操作を録画。カットごとに個別クリップで書き出し（差し替え・調整しやすくするため）
3. **図解スライド**（Claude・Canva 上に作成）— 冒頭の仕組み図解、タイトル/締めカット。編集可能な状態で引き渡す
4. **ナレーション音声** — 原稿確定後に生成。手段は下記 4 章から選択
5. **仮組み**（Claude）— 素材一式＋タイムライン指示書を用意し、Canva の動画エディタ上でドラフトを組んだ状態まで進める。BGM・間・テロップの微調整は発注側が Canva 上で実施

### 発注側にお願いする可能性があるもの
- ElevenLabs を使う場合の音声生成（または VOICEVOX で自動生成に切り替え）
- 最終の BGM 選定と書き出し（Canva 内で数分の作業）
- 「本番の Gmail に返信して自動検知される瞬間」など、本番環境でしか撮れないカットが必要になった場合の録画

## 4. ナレーション音声の選択肢（開始指示時に指定）

| 手段 | 特徴 |
|---|---|
| VOICEVOX | 無料・商用可。原稿から自動生成でき、修正が容易 |
| ElevenLabs | 自然さ重視。発注側アカウントでの生成が必要 |
| 人力収録 | 原稿のみ Claude が用意し、発注側で収録 |

合成音声は後日の原稿修正時に再生成が容易な点で有利。

**決定: VOICEVOX の「No.7」を使用**。アカウント登録は不要。動画内に「VOICEVOX:No.7」のクレジット表記を入れること。

## 5. 素材作成上の注意

- 本番環境の実データ（実メール・個人情報）は映さない。**ローカル環境＋デモ用データ**で撮影する
- 操作録画は Playwright による自動操作で行い、手ブレなし・一貫したカーソル動作で撮る
