# 勤怠管理（eWorks）計算仕様 — 勤務時間

- 作成: 2026-11-18（Phase 0）。FileMaker「eWork2」の作業明細 75,828 件と勤務表月締め 2,626 件から復元し、現行の値と突き合わせて確認
- 方針: 計算は現行どおり。**新しく加わるのは打刻時刻の丸めと予定へのそろえ**（計画書 決定事項 7）

## 1. 1 件（作業明細 1 行）の時間

### 1-1. 開始・終了時刻（新システム）

1. 打刻の時刻を 30 分単位で丸める: 出勤は**切り上げ**（8:45 → 9:00）、退勤は**切り捨て**（17:20 → 17:00）。ちょうどの時刻はそのまま
2. 予定の範囲にそろえる: 開始 = max(丸めた出勤, 予定開始)、終了 = min(丸めた退勤, 予定終了)
3. 管理者が日別入力で直した時刻があれば、それを優先する（直す前の値と直した人を残す）
4. 打刻がない日は予定の時刻（現行の「実績がなければ予定」と同じ）。打刻のない予定日は要確認に出す

> 現行は「手入力の実績 → 取り込んだ実績 → 予定」の順で、最初に値があるものを採用している。

### 1-2. 休憩（自動）

| 条件 | 休憩 |
|---|---|
| 担当者に例外休憩（曜日別）がある | その時間（現在は 1 名、平日 12:00〜12:30 = 0.5 時間） |
| 開始が **12:00 より前**、かつ終了が **13:00 より後** | **1 時間**（休憩時間帯 12:00〜13:00 をまるごと含む場合だけ） |
| それ以外（例: 6:00〜13:00、12:00〜17:00、6:15〜12:15） | 0 |

- 休憩時間帯は設定値（現行 Parm: 12:00〜13:00 の 1 枠。最大 5 枠まで持てる）
- 時間帯に**一部だけ重なる場合は差し引かない**（例: 6:15〜12:15 は 6 時間のまま）
- 確認: この規則で 2014〜2026 年の全 51,401 件が現行の「総時間」と一致

### 1-3. 時間の内訳

```
総時間   = 終了 − 開始 − 休憩（時間は「時＋分÷60」、小数 2 桁）
作業時間 = 総時間 − 追加休憩（手入力。現行は全件 0）
通常時間 = 作業時間 − 残業時間 − 休日時間
```

- **残業時間・休日時間は手入力**（自動判定はしない）。現行の入力実績は 2025 年以降で残業 4 件・休日 88 件（土曜出勤など）
- 予定にそろえるため、打刻から自動で残業が生じることはない（業務の性質上、残業は想定しない。決定事項 7）
- 欠勤の日は作業時間 0

## 2. 月の合計

- 通常・残業・休日の各時間を、担当者 × 月で作業明細から合計
- 確認: 勤務表月締めの月合計と 2,621／2,626 か月で一致（不一致 5 件は 2014 年の初期データのみ）
- 交通費は日別の金額を合計。皆勤・通勤手当は現行どおりチェックで付ける

## 3. 確認事項

- 1-2 の規則では、6 時間を超えても 12:00〜13:00 をまたがない勤務（例: 6:00〜13:00 の 7 時間）は休憩 0 になる。
  労働基準法では 6 時間超の勤務に 45 分以上の休憩が必要。現在の出退勤パターン（37 種）に該当するものはないが、
  新システムで予定を作るときに「6 時間超で休憩 0」を警告として出すことを提案する
